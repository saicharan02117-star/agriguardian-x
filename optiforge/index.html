The browser demo uses explainable visual signals and safe uncertainty handling. The broader crop library is a source-traceable knowledge layer, not an unsupported claim of extra trained classes.

Decision policy

  1. Validate file and image quality.
  2. Extract color, texture and lesion signals.
  3. Estimate supported-class probabilities.
  4. Abstain when confidence or image quality is low.
  5. Show treatment guidance only as source-traceable support and save the result only after farmer approval.

Model boundaries

A confidence score measures model certainty among supported classes. It does not prove the biological diagnosis. Field performance may differ from controlled leaf datasets.

Security controls
